## Эзний гарын авлага (та юу хийх вэ)

Сайт **хоёр талтай** гэж бод:

- **Үзэгчийн тал** = дээрх линк. Хэрэглэгч бүр үүнийг л хардаг: каталог, player, coin.
- **Эзний (таны) тал** = энэ компьютер дээрх энэ хавтас + доорх 3 скрипт. Та кодчлол мэдэх шаардлагагүй — PowerShell нээгээд (энэ хавтас дотор) дараах коммандуудыг л ажиллуулна.

### 1. Шинэ бичлэг (цуврал) нэмэх

```powershell
.\tools\add-series.ps1 -Video "C:\зам\кино.mp4" -Title "Цувралын нэр" -Tagline "Товч танилцуулга"
```

Скрипт өөрөө: бичлэгийг 20 секундын ангиудад хэрчинэ (хэвтээ бол 9:16 болгож тайрна), poster зураг гаргана, каталогт бүртгэнэ. Ангиудын нэрийг өөрчлөхийг хүсвэл `src\data\catalog.json` файлыг нээж засна. Дараа нь:

```powershell
.\tools\deploy.ps1
```

— 1-2 минутын дараа сайт дээр гарчихна.

### 2. Мөнгө орж ирэхэд код өгөх

Хэрэглэгч таны данс руу шилжүүлээд Facebook-ээр мэдэгдэнэ. Та шилжүүлгээ хараад:

```powershell
.\tools\make-code.ps1 -Coins 100
```

— гарч ирсэн кодыг (жишээ: `MD100-A7K2-3F9B1C`) хэрэглэгчид илгээнэ. Хэрэглэгч аппын «Цэнэглэх» цонхонд оруулахад coin нь шууд нэмэгдэнэ. Код нэг л удаа ашиглагдана.

### 3. Дансаа тохируулах

`src\config.ts` файлыг нээгээд: банк/дансны дугаар/нэрээ бичих, `codeSecret`-ийг өөрийн нууц үгээр солих, туршилт дуусахаар `demoMode: false` болгох. Дараа нь `.\tools\deploy.ps1`.

## Юу ажилладаг вэ (S0)

- **Каталог** — цувралын карт, үзсэн явцын тэмдэглэгээ
- **Цувралын хуудас** — ангиудын жагсаалт, үнэгүй/түгжээтэй төлөв, "үргэлжлүүлэх" товч
- **Босоо player** — TikTok-style scroll-snap feed, дээш шудрахад дараагийн анги, идэвхтэй анги автоматаар тоглоно, зэргэлдээ анги урьдчилж ачаалагдана, дуу асаах товч (autoplay-ийн шаардлага)
- **Coin систем (демо)** — эхний 2 анги үнэгүй; дараагийн анги 30 🪙; багцаар нээх хямдрал (50 🪙); цэнэглэх modal (одоогоор демо coin, QPay дараагийн шатанд)
- Бүх төлөв localStorage-д (coin, нээсэн анги, үзсэн явц) — backend-гүй
- Монгол UI, PWA manifest, HashRouter (статик хостинг дээр тохиргоогүй ажиллана)

Демо контент: tale2film-ийн босоо бичлэгүүдийг 13–14 секундын "анги" болгон хэрчсэн (`public/videos/`).

## Ажиллуулах

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ — статик хостинд бэлэн
```

## Тэг зардлын deploy зам

`npm run build` → `dist/`-ийг **Cloudflare Pages**-д (үнэгүй) байршуулна. Видеонууд одоогоор `public/`-д — каталог томрохоор **Cloudflare R2** (10GB үнэгүй, egress 0₮) + ffmpeg HLS руу шилжинэ.

## Дараагийн шатууд (roadmap)

| Шат | Агуулга |
|---|---|
| S1 | Supabase auth + coin ledger сервер талд (localStorage → DB) |
| S2 | QPay v2 цэнэглэлт (invoice → deeplink → callback → payment/check → ebarimt) |
| S3 | R2 + HLS (hls.js), signed URL |
| S4 | Жинхэнэ контент (лиценз эсвэл rev-share — судалгаа хийгдсэн) |
